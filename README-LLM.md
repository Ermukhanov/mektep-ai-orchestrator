LLM (ALEM) local test
======================

Как локально проверить подключение к ALEM (llm.alem.ai):

1. Скопируйте `.env.example` в `.env` и добавьте ваш ключ:

ALEM_API_KEY=sk-ВАШ_КЛЮЧ

2. Запустите тестовый скрипт (нужен Node.js 18+):

```bash
node scripts/test-alem.js
```

3. Ожидаемые ответы:
- HTTP 200 и JSON-ответ от ALEM. Если статус 401/403 — ключ неверен.

Безопасность: не коммитьте `.env` и не публикуйте ключи в чатах.
